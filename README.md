# TUINA BUSINESS — Version finale

- Aucun compte client.
- Aucun moyen de paiement affiché.
- Aucun panier.
- Chaque produit affiche son prix quand il est défini.
- Le bouton « Acheter sur WhatsApp » ouvre directement WhatsApp au +226 57 08 65 91.
- Le message contient le nom, le prix et le lien public vers la photo du produit.
- Seul le propriétaire du site modifie le catalogue dans `script.js` et les photos dans `images/`.

### Important
Un simple lien WhatsApp ne peut pas joindre automatiquement une photo comme pièce jointe. La version actuelle ouvre WhatsApp avec le lien de la photo. Pour joindre réellement l'image automatiquement, il faudra une intégration WhatsApp Business API avec backend.
